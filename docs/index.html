📋 Reglamentos

Objetivo

Partido al mejor de 5 goles. Si el marcador llega a 2-2, va inmediatamente a penales.

Acciones ofensivas

AcciónDescripción
Patear al arcoJugar Disparo al arco → fase de disparo con dados
Pasar la pelotaJugar Pase → la pelota pasa a un compañero
Pasa de turnoRetener la pelota sin pasar ni disparar
Reventar la pelotaDespeje — duelo de dados entre un jugador de cada equipo

Reacciones defensivas

Si el ataque…La defensa puede…
Pasó la pelotaRobo pelota (anulable con Gambetear)
Pasó de turnoTrampa de offside, Marca personal

Una sola carta defensiva por carta ofensiva jugada.

Rebote: gol y atajada a la vez → se repite. Palo: mismo número en ambos dados → se repite.

Reventarla

  1. Un jugador de cada equipo tira un dado (no el que dijo "la reviento").
  2. El más alto se queda con la pelota.
  3. Si gana el mismo equipo, cuenta como un pase completado.

Partido al mejor de 5 goles. Si el marcador llega a 2-2, va inmediatamente a penales.

🔍 Hallazgos

v0 — se estanca

  • 99% de partidos supera 500 turnos sin definirse.
  • Promedio de 0,66 goles — casi nunca llega a 2-2 ni a penales.
  • Pasa de turno deja la pelota en el mismo jugador si la defensa no reacciona → posible bucle.

Para discutir: ¿el turno pasa a un compañero si nadie reacciona? ¿Límite de cedidas seguidas?

v1 — más dinámico

  • 60% de partidos termina con ganador; ~3,2 goles por partido.
  • Reventar la pelota y Robo pelota destraban el juego vs v0.
  • Balance razonable: 32,5% vs 27,5% victorias.
  • 40% aún se estanca — ver si pasa en mesa o es la IA.
  • Trampa/Marca casi no se usan (~1× por partido) — cartas situacionales.

Preguntas abiertas

  • ¿Qué pasa si nadie reacciona al pasa de turno?
  • ¿Con qué frecuencia usan pasa de turno en mesa?
  • ¿3 goles cierran el partido además del 2-2?
  • ¿El 40% de partidos colgados en v1 pasa con humanos?

💻 Simulador

Podés correr partidos automáticos desde el repo clonado:

# Comparar v0 vs v1 (200 partidos c/u)
python3 -m simulador compare

# Solo v1
python3 -m simulador run --reglas v1 --partidos 100

# Ver un partido turno a turno
python3 -m simulador run --reglas v1 --partidos 1 --verbose

Requisito: Python 3.11+ (solo biblioteca estándar).
