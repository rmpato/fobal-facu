Fobal Facu

Simulador de partidos de cartas — correr miles de partidos, comparar reglamentos y ver conclusiones antes de jugar en mesa.

python3 -m simulador run Reglamento v2 en simulación 100% partidos completados (v2)

Empezar rápido

git clone https://github.com/rmpato/fobal-facu.git
cd fobal-facu
python3 -m simulador reglamentos list
python3 -m simulador run --reglamento v1 --partidos 200
python3 -m simulador compare-reglamentos --partidos 200
