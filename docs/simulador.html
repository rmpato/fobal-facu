Usar el simulador

Es un programa chico que se corre en la propia computadora. Necesita Python 3.11 o más nuevo y nada más: no hay que instalar bibliotecas ni crear cuentas.

Ponerlo a andar

macOS y Linux

git clone https://github.com/rmpato/fobal-facu.git
cd fobal-facu
./instalar.sh --web

Windows

git clone https://github.com/rmpato/fobal-facu.git
cd fobal-facu
.\instalar.bat --web

El script comprueba que Python esté y sea suficientemente nuevo, avisa cómo instalarlo si falta, corre las pruebas y abre la interfaz en http://localhost:8000. Todo pasa en la propia máquina: no manda nada a internet y los cambios quedan como archivos del repositorio.

Sin el --web, el script deja todo listo y muestra los comandos disponibles. Quien no tenga Python lo encuentra en python.org (en Linux suele venir puesto). Para bajar el repositorio sin usar git, GitHub ofrece un ZIP en el botón «Code».

Las tres pantallas

Reglas

Acá se edita una versión del juego, con todo a la vista: cuántas copias de cada carta van al mazo, cuántas cartas tiene cada uno en la mano, cuándo se levantan cartas nuevas, la tabla del dado, qué puede hacer el que tiene la pelota y con qué cartas responde la defensa.

Mientras se escribe, el programa avisa si algo no cierra: un mazo que no alcanza para repartir, una carta que la defensa usaría pero no está en el mazo, un ataque que se podría quedar sin jugadas posibles.

Simular

Se eligen dos o más escenarios —una versión, un formato, un estilo de juego— y cuántos partidos correr de cada uno. Doscientos alcanzan para ver tendencias; con quinientos las diferencias chicas dejan de moverse entre corrida y corrida. Como todos usan las mismas semillas, lo que cambia entre escenarios es la regla y no la suerte.

Ver un partido

Un partido completo, jugada por jugada, con el marcador arriba. Es la forma de entender de dónde salen los números: si una versión da partidos larguísimos, acá se ve por qué. Se le puede poner nombre a los jugadores y repetir exactamente el mismo partido anotando su semilla.

Cambiar el juego sin programar

Casi todo lo que se puede querer probar es un campo de la pantalla de reglas:

Para probar…Dónde
Sacar o agregar copias de una cartaMazo
Manos más grandes o más chicasManos y reposición
Que se levanten cartas en otro momentoManos y reposición
Que sea más fácil o más difícil el golDisparo al arco
Sacar el pasa de turnoQué puede hacer quien tiene la pelota
Que la trampa se juegue contra el paseCómo responde la defensa
Cambiar cuántos goles hacen faltaPartido

Se guarda, se simula y se compara con la versión anterior. Lo único que necesita programar es una carta nueva con un efecto que el motor todavía no conozca.

Desde la terminal

Todo lo de la interfaz también se puede hacer con comandos:

python3 -m simulador reglamentos            # qué versiones hay
python3 -m simulador reglamentos v2         # qué reglas aplica una versión
python3 -m simulador simular v2 --partidos 500
python3 -m simulador comparar v1 v2 --formatos 3 4
python3 -m simulador ver v2 --semilla 42    # un partido, jugada por jugada
python3 -m simulador ver v2 --grabar partido.html   # y guardarlo para compartir

La referencia completa está en el repositorio: guía de comandos.

Para leer el código

Son unas dos mil líneas, en castellano y sin bibliotecas externas. Hay un recorrido comentado —qué hace cada archivo, cómo se resuelve un turno, dónde tocar para agregar una carta— en la guía del código.

Y hay ochenta pruebas automáticas que verifican lo importante: que no se pierdan cartas, que los partidos terminen, que la misma semilla dé siempre el mismo partido. 

python3 -m unittest discover
