💻 Simulador

Comandos para correr partidos, comparar reglamentos (v0–v2) y ver un partido en terminal o replay web. Guía completa: guia-rapida.md.

Instalación

git clone https://github.com/rmpato/fobal-facu.git
cd fobal-facu
python3 --version   # 3.11+

Solo biblioteca estándar. Opcional: rich / textual para espectador con mejor UI.

Todos corren con el mismo CLI — default 3 vs 3 (--jugadores-por-equipo 3)

python3 -m simulador reglamentos list

Comandos esenciales

Correr partidos

# Reglamento en playtesting (recomendado para mesa nueva)
python3 -m simulador run --reglamento v2 --partidos 200 --ia estrategica

# Baseline histórico
python3 -m simulador run --reglamento v1 --partidos 200 --ia estrategica

# Un partido con detalle
python3 -m simulador run --reglamento v2 --partidos 1 --verbose

Comparar todos los reglamentos

python3 -m simulador compare-reglamentos --partidos 200 --ia estrategica

Ver partido en terminal + replay web

python3 -m simulador ver --reglamento v2 --semilla 42 --pausa 3
python3 -m simulador ver --reglamento v2 --semilla 42 --sin-pausa --grabar docs/replays/mi-partido.json

# Perfiles distintos por equipo
python3 -m simulador ver --reglamento v2 --ia-equipo0 agresiva --ia-equipo1 conservador

Reproducir JSON en el navegador → Replay (GitHub Pages o python3 -m http.server en docs/).

¿v1.2, v2.1 o v3? → Cómo crear un reglamento

Qué mirar en el reporte

  • Reglas aplicadas — qué interpretó el motor para ese reglamento
  • Completados vs empates técnicos (>500 turnos)
  • Acciones % — pase, despeje, robo, disparo, pasa turno (0% en v2), falta
  • Trampa / Marca — colocadas y efectivas (v1: al pasa turno · v2: al pase)
  • Goles promedio · % penales · cartas jugadas

Conclusiones → resultados · recomendaciones.

Variantes (sin reglamento nuevo)

Ajustes en configs/variantes.json sobre un reglamento base — útil para experimentos rápidos:

python3 -m simulador variantes --partidos 200 --ia estrategica

Reglas formales (v1.1, v2) preferí registrarlas como reglamento en reglamentos/.
