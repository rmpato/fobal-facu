Inicio / Simulador

💻 Simulador

Comandos esenciales. Documentación completa en el repo: guia-rapida.md.

Instalación

git clone https://github.com/rmpato/fobal-facu.git
cd fobal-facu
python3 --version   # 3.11+

Comandos esenciales

Correr partidos

python3 -m simulador run --reglamento v1 --partidos 200
python3 -m simulador run --reglamento v1 --partidos 1 --verbose

Reglamentos

python3 -m simulador reglamentos list
python3 -m simulador reglamentos show v1

¿Querés crear v1.2, v2 o v3? → Cómo crear un reglamento

Comparar versiones

python3 -m simulador compare-reglamentos --partidos 200
python3 -m simulador compare --partidos 200

Ver partido + replay web

python3 -m simulador ver --semilla 42 --pausa 3
python3 -m simulador ver --semilla 42 --sin-pausa --grabar docs/replays/mi-partido.json

Reproducir en el navegador → Replay (GitHub Pages o local con python3 -m http.server en docs/).

Qué mirar en el reporte

  • Reglas aplicadas — qué interpretó el motor
  • Completados vs empates técnicos (>500 turnos)
  • Acciones % — pase, despeje, robo, disparo, pasa turno, falta
  • Goles promedio · % penales · cartas jugadas
