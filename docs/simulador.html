💻 Simulador

Correr partidos automáticos desde la terminal para probar cambios de reglas antes de jugar en mesa.

Requisitos

Python 3.11+ · solo biblioteca estándar · repo en GitHub:

git clone https://github.com/rmpato/fobal-facu.git
cd fobal-facu

Comandos básicos

100 partidos v1 (IA estratégica — default)

python3 -m simulador run --reglas v1 --partidos 100

Ver un partido turno a turno

python3 -m simulador run --reglas v1 --partidos 1 --verbose

Comparar v0 vs v1

python3 -m simulador compare --partidos 200

IA simple (comportamiento viejo)

python3 -m simulador run --reglas v1 --partidos 100 --ia simple

Variantes de reglas

Probar reglas alternativas sin tocar código — archivo configs/variantes.json

Comparar variantes (500 partidos c/u)

python3 -m simulador variantes --partidos 500
VarianteComportamiento
baselineSi nadie reacciona al pasa de turno → pelota queda en el mismo jugador
pasa_companeroSin respuesta defensiva → pelota pasa a un compañero

Una variante puntual

python3 -m simulador run --reglas v1 --partidos 200 \
  --pasa-turno-sin-respuesta pasa_companero

Qué mira el reporte

  • Acciones (%): pase, disparo, robo, despeje, pasa de turno, falta
  • Trampa / Marca: colocadas y efectivas
  • Completados vs empates técnicos (>500 turnos)
  • Goles promedio y % penales
  • Cartas jugadas por partido

Compará esos % con lo que pasa en mesa → ver resultados · cómo funciona la simulación.
