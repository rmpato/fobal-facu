¿Quiénes juegan?

Los nombres se usan para mirar los partidos: hacen que el relato se entienda. Para las estadísticas da igual cómo se llamen, pero cuántos son cambia mucho el juego.

Se guardan en configs/equipos.json, así que quedan para la próxima vez.

Las reglas del juego

Cada reglamento es una versión del juego. Se puede editar el mazo, cuántos goles hacen falta para ganar y qué cartas puede jugar cada equipo. Al guardar, queda listo para simular.
